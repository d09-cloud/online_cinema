Сервис представляет собой онлайн-кинотеатр с базой фильмов и сериалов, доступных для просмотра в любое время.
Запуск: команды npm install и npm start
Основные функции:
Регистрация и авторизация пользователей — создание личного аккаунта с профилем.
Просмотр фильмов и сериалов — доступ к библиотеке содержимого с наличием пауз и перемоток.
Комментарии и оценки — возможность оставлять отзывы с оценками к фильмам и играм.
Структура проекта: src, tools
